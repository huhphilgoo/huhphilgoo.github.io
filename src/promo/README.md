# promo — 랜딩 페이지 광고 이미지

앱 화면만 달랑 넣은 스크린샷 대신, **헤드라인 + 기기 장면 + 실제 앱 화면**으로 된 광고 이미지를
만드는 틀이다. VelozPad 가 첫 사례다(`velozpad/`). 다른 앱도 이 폴더를 복사해 시작하면 된다.

```
src/promo/
  render.py              장면 × 언어를 렌더해 <slug>/assets/<장면>_<언어>.jpg 로 저장
  <slug>/
    template.html        1600×1000 한 장 = 장면 하나. #scene=…&lang=… 로 고른다
    promo.json           장면·언어 목록, 원본에서 잘라 쓸 조각
    raw/                 실제 앱 화면 원본(2배율 PNG) — 템플릿은 이것만 쓴다
    capture_test.dart    raw/ 를 다시 뽑는 Flutter 테스트 (앱 저장소에서 돌린다)
```

## 만드는 순서

1. **앱 화면 원본을 뽑는다** — `capture_test.dart` 를 앱의 `test/` 에 잠깐 복사해 언어마다 돌린다
   (파일 맨 위 주석에 명령이 있다). 끝나면 앱 저장소에서 지운다.
2. **렌더한다** — `python3 src/promo/render.py <slug>` (Google Chrome, Pillow 필요). **이미지를 바꿨으면 `promo.json` 의 `prefix` 도 바꾼다** — 이름이 같으면 브라우저가 옛 그림을 계속 보여 준다
3. **`apps.json` 의 `landing.shots`** 에 이미지와 언어별 `[alt, 캡션]` 을 적고 `python3 src/build.py`

렌더만 확인하려면 브라우저로 `template.html#scene=hero&lang=ko` 를 열면 된다.

## 이미지가 놓이는 자리 (`build.py`)

| `shots` 순서 | 자리 |
|---|---|
| 0 | 맨 위(히어로). 허브 카드 표지로도 쓰인다 |
| 1 | "들어 있는 것" 아래 (팔레트가 있는 앱은 팔레트 섹션) |
| 2 | 맨 아래 마무리 |
| 3 이후 | "들어 있는 것" 아래, 1 다음에 차례로 |

3장 이하인 앱은 예전과 똑같이 나온다.

## 디자인 원칙 — 지키지 않으면 사용자에게 되돌려받았다

- **밝은 바탕.** 어두운 배경으로 시작하지 않는다(요청이 있을 때만). 강조 글자는 앱의 밝은 색 대신
  같은 계열의 진한 색 — 밝은 바탕 위 노란색은 흐리다
- **헤드라인 한 줄, 강조는 한 단어.** 긴 언어는 템플릿이 글자를 줄여 한 줄에 넣고, 안 되면 두 줄
- **앱 화면은 진짜만.** 합성은 기기 틀·배경·말풍선까지. 버튼·설정 화면은 `raw/` 캡처를 쓴다.
  빛나는 효과처럼 테스트 렌더러가 못 그리는 것(blur)만 CSS 로 덧그린다
- **사실만.** 말풍선의 단축키(예: 컷 ⌘B)는 앱 프리셋에 실제로 있는 것. 가짜 QR 은 모양만 흉내 낸 무늬
- **문구에 특정 기기 이름을 쓰지 않는다**(VelozPad: "Mac"·"아이폰" 대신 "PC"·"휴대폰"). 그림은 괜찮다
- **기기 비율은 실물대로.** 노트북 화면 16:10, 밑판은 두께와 경사. 옆으로 늘이면 납작해 보인다

## 글꼴에서 헛디딘 것

- 테스트에서 글꼴을 지정하지 않은 글자는 `FlutterTest` 글꼴(네모)로 나온다. `capture_test.dart` 의
  `theme()` 이 제목·채운 버튼까지 실어 둔 글꼴로 덮는다
- 일본어 글꼴(Hiragino)은 ⇧ 를 가는 화살표로 그린다. 앱 캡처에서는 ⇧ 없는 예시(⌘C)를 쓰고,
  템플릿의 `kbd` 는 기호 글꼴을 먼저 쓴다
- 템플릿에서 영어·스페인어가 한국어 글꼴을 먼저 잡으면 `ó` 만 다른 글꼴로 크게 나온다 —
  `html:lang(…)` 로 언어별 글꼴 순서를 정해 두었다
